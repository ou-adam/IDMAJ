  SECTION 6 — INFRASTRUCTURE & MATÉRIEL
================================================================================

  A. DOUCHETTE DE SCAN QR CODE — 20 000 DA
  ------------------------------------------
  Matériel : 1× Lecteur QR Code USB/Bluetooth
    - Type       : Pistolet scanner 1D/2D (QR Code, DataMatrix, Code 128…)
    - Connexion  : USB-HID + Bluetooth (dual mode)
    - Distance   : 5 cm à 50 cm
    - Compatib.  : Windows, Linux, Mac — Plug & Play, aucun driver requis
    - Garantie   : 1 an fabricant

  B. HÉBERGEMENT ICOSNET VMware VPS — 84 000 DA / 6 mois
  ---------------------------------------------------------
    - CPU          : 2 vCores minimum
    - RAM          : 8 Go minimum
    - Stockage     : 100 Go SSD
    - Bande passante : Illimitée
    - IP dédiée    : Oui (localisée en Algérie)
    - OS           : Ubuntu 22.04 LTS
    - Datacenter   : Alger, Algérie (conformité réglementaire)
    - Uptime SLA   : 99.9%
    - Protection DDoS incluse

  Stack technique déployée :
    Ubuntu 22.04 LTS
    ├── Nginx (serveur web haute performance)
    ├── PHP 8.2 + php-fpm
    ├── MySQL 8.0 (base de données principale)
    ├── Redis (cache + sessions temps réel pour scan QR)
    ├── Supervisor (gestion des queues d'emails)
    ├── Let's Encrypt (SSL automatique)
    ├── UFW Firewall (ports 80, 443, 22 uniquement)
    └── Cron jobs (sauvegardes quotidiennes)

  C. DOMAINE IDMADJ.DZ — 5 000 DA (frais dossier NIC-DZ)
  ---------------------------------------------------------
    Géré via ICOSNET (Registrar agréé NIC-DZ)
    Frais uniques de traitement du dossier

  D. EMAILS TRANSACTIONNELS BREVO — 8 000 DA / 6 mois
  ------------------------------------------------------
    Plan Starter : 20 000 emails/mois
    Intégration SMTP standard avec Laravel
    Alternative gratuite : Brevo Free (300 emails/jour)
